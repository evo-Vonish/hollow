## 二、项目本质(一句话)

免费开源(AGPL-3.0)深度研究 API:**多源搜索召回 → 三档升级全文爬取 → 正文净化 → 可溯源 Evidence Pack**,之上生长 Semantic Reader。核心哲学:**借力基建(SearXNG/Scrapling/trafilatura),自研差异化(编排层/Evidence/阅读器)**。v1 死于"自研了该借力的基建"。

阶段:P1 搜索 API → P2 爬取 API → P3 净化+Evidence → P4 Semantic Reader 前端 → P5+ Agent。每阶段独立可用是验收底线。

## 三、已定案的架构决策(用户拍过板)

1. **不依赖 Docker**。SearXNG 以本地 Python 进程直跑 vendor 源码(已实测)。可后续演进为"进程内库集成"(import 引擎层,跳过 Flask/limiter/JSON,能拿到结构化 error_type/suspended)。
2. **不做语言转写 / 不重写引擎适配器**。这是 v1 的死法。249 个引擎适配器 + traits 数据的维护债必须留给上游社区。我们只保留底层(引擎/网络/traits)、自研顶层(编排+API)、丢弃中间层(Flask/limiter/前端)。
3. **全栈 Python**:FastAPI + SearXNG + Scrapling + trafilatura。
4. **SearXNG 前端不复用**:simple 主题的 preferences 是 cookie 驱动的 SSR 表单,气质(要冷白 Semantic Reader)和技术栈都对不上,要被 P4 自研取代。但其"设置数据模型"(引擎/分类/偏好存差异 + URL 导出)思路可借鉴。

## 四、实测确认的关键事实(云沙箱,★=可能因环境变化需重测)

### SearXNG(已部署跑通)
- `POST /search` form-urlencoded + `format=json` + 浏览器风格头 → 7 键 JSON。`/healthz` 200。
- `unresponsive_engines` 确认序列化为 `[["engine","翻译文案"]]`;超时=`[["arxiv","timeout"]]`;熔断=`"Suspended: too many requests"` 前缀。**丢失结构化 error_type/suspended**——网关需"请求集−结果集−失败集"差集兜底。
- 结果每条带 `engine`(单)/`engines`(复,数组,多来源用这个)/`score`/`positions`/`parsed_url`(6元素数组)。arxiv 还带 doi/authors/pdf_url/tags。
- `avg 1 2 3` → answerer 短路,只回 answer、results=0。
- `!!g test` → **302 跳 google,连 json 都被劫持** → 网关必须 bang 防护。
- count 不可控:ddg pageno=1 返 10 条、pageno=2 返 15 条。
- **引擎实测可用性(数据中心 IP)**:✅ wikipedia/arxiv/duckduckgo/**baidu/sogou/bilibili**/bing;❌ brave(too many requests)/startpage(access denied)/mojeek(access denied)/quark(HTTP error)。★中文源在数据中心 IP 意外可用,推翻了"上游默认全关=不好使"的担忧。

### Scrapling(静态跑通,浏览器推迟)
- `pip install "scrapling[fetchers]==0.4.10"` → curl_cffi 0.15.0。
- ★**沙箱坑**:curl_cffi 默认 `impersonate="chrome"` 的 TLS 指纹被 egress 代理重置(curl 35)。关掉(`impersonate=None`)+ `CURL_CA_BUNDLE` 则过代理成功(arxiv 200/42KB/4652字符)。**本地直连应恢复 `impersonate="chrome"`**(那是绕反爬的卖点)。
- ★浏览器档:Chromium 预装 1194 ≠ Scrapling 要的 1228(playwright 1.61.0);用 `executable_path` 能启动,但导航失败(Chromium 没走代理)。**本地环境应重测**——装匹配 chromium + 直连后大概率可用。
- 三档零耦合、无内置升级链(网关编排)。无浏览器池/无硬超时/无杀进程能力 → 全靠网关补(Semaphore + wait_for + close 重建 Session)。
- timeout 单位坑:静态=秒、浏览器=毫秒、外层 wait_for=秒。隐身档 solve_cloudflare=True 时会话级 timeout 须 ≥60000ms。
- 交 trafilatura 的 raw HTML 用 `resp.body`(bytes),不是 html_content/text。

## 六、第一个 API 设计(`docs/design/03`,已研究待动手)

`POST /v0/research {q,...}` → SearXNG 搜索 → top-N(默认5)→ **asyncio.gather 并行静态抓取**(Semaphore+wait_for+占位)→ trafilatura 净化 → Evidence Pack 返回。

- **MVP 范围**:搜索 + 并行**静态**抓取 + 净化。浏览器升级链(动态/隐身)推迟第二版。
- 搜索侧失败(engines_failed)与抓取侧失败(fetch_status)分两套汇报,都禁止静默丢弃。
- 不变量:`items 数 = fetch.requested = ok+failed+timeout+blocked`。
- 代码结构规划:`api/{main,config,searx_client,fetcher,purifier,orchestrator,models}.py`。
